# UsoJaleco

Aplicativo local para consultar, adicionar e editar protocolos.

View your app in AI Studio: https://ai.studio/apps/38d9b1b1-1c81-45ce-ba32-9a40911273cf

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Data

Os protocolos ficam salvos em `data/protocols.json`.

Quando um protocolo e criado, editado ou excluido pela tela "Adicionar / Editar", o servidor local atualiza esse arquivo.
